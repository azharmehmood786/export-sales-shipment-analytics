# Export Sales Shipment Analytics

## Project Overview
This project focuses on analyzing export sales and shipment data using Python, SQLite, and SQL.

The goal is to generate realistic business datasets, store them in a database, and calculate key business performance indicators (KPIs).

## Tools & Technologies
- Python
- Pandas
- NumPy
- SQLite
- SQL
- Jupyter Notebook

## Datasets
The project includes three datasets:

- Orders: Order and shipment information.
- Products: Product details and pricing.
- Customers: Customer information.

## Key Performance Indicators (KPIs)

1. **Total Export Volume:** Measures the total quantity of exported products.
2. **Average Order Value:** Measures the average monetary value of orders.
3. **On-Time Shipment Rate:** Measures the percentage of shipments delivered on time.

## Project Workflow
1. Generate realistic sample data using Python.
2. Create Orders, Products, and Customers datasets.
3. Load CSV files into SQLite.
4. Write SQL queries to calculate business KPIs.
5. Analyze results and extract business insights.
